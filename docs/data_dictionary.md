# Data dictionary

Generated by `aco_scorecard/docs.py` from the dbt manifest and catalog (warehouse column types) and the schema mapping.
Metric definitions are in [metric_definitions.md](metric_definitions.md); the period by period source mapping is in
[schema_mapping.md](schema_mapping.md).

Layers: `raw` (CSV text as published, one table per file), `staging` (one generated view per file: typed, renamed,
units converted), `intermediate` (periods stacked, ACO identifier bridge, derived values), `core` (conformed
dimensions and facts), `reporting` (marts with window functions), `reference` (seeds).

## core.dim_aco

One row per ACO across all years, keyed by the conformed aco_key, with attributes from its latest period.

| column | type | description |
|---|---|---|
| `aco_key` | varchar | Published ACO_ID (PY 2018 on), the bridged ACO_ID for legacy rows, or LEGACY-<ACO_Num> when no bridge exists. |
| `aco_name` | varchar | ACO doing business as name, or legal business name when no DBA exists. |
| `published_aco_id` | varchar | Unencrypted ACO_ID, when the ACO appears in PY 2018 or later. |
| `legacy_aco_num` | varchar | Encrypted ACO_Num used in PY 2013 to 2017, when the ACO appears in those years. |
| `aco_key_method` | varchar | How aco_key was assigned: published_aco_id, bridged_legacy_id or legacy_id_only. |
| `first_performance_year` | integer | First year the item appears in the data. |
| `last_performance_year` | integer | Last year the item appears in the data. |
| `performance_years_reconciled` | bigint | Distinct performance years the ACO was reconciled. |
| `performance_periods_reconciled` | bigint | Performance periods the ACO was reconciled (an ACO in both PY 2019 periods counts twice). |

| `latest_performance_period_id` | varchar | Most recent period the ACO appears in. |
